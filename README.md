# Terra-Addons — Experiments

Experimental / sandbox addons that are **not** part of the `main` branch and do **not** appear in Terra's in-game GitHub Addon Catalog.

## Addons in this branch

- **`custom-avatar`** — Import arbitrary rigged `.glb` 3D character models (Half-Life 2, Fortnite/Unreal, Smash Bros., Nintendo/BotW, Mixamo, VRM) and animate them live on Biketerra's bike using Biketerra's real-time rider skeleton.

## Installing manually

Download a folder from this branch as a `.zip` and install it via Terra's **Addons → Upload `.zip`** button, or copy the addon folder directly into `~/.local/share/terra/addons/`.
